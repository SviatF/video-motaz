# PTS Creative Studio — Video Montage MVP

Безкоштовний онлайн-відеоредактор для рекламних креативів, який можна розгорнути на **Cloudflare Workers (Static Assets)** або **Cloudflare Pages**. Без платних ліцензій, AI API, серверів рендеру чи платних SDK.

## Cloudflare Workers (як на поточному екрані Create application)

Налаштування для GitHub-репозиторію **SviatF/video-motaz**:

- Project name: **video-motaz**
- Build command: **bash build.sh**
- Deploy command: **npx wrangler deploy**
- Preview command: **npx wrangler preview**
- Production branch: **main**

У корені є файл **wrangler.json** із `assets.directory = "./dist"` — саме він повідомляє Workers, що після запуску build.sh слід публікувати статичний сайт із папки dist. Після першого деплою Workers Builds відстежуватиме push у main.

## Cloudflare Pages (GitHub deploy)

1. Cloudflare Dashboard → **Workers & Pages** → **Create application** → **Pages** → **Import an existing Git repository**.
2. Вибрати **SviatF/video-motaz**, production branch **main**.
3. Framework preset: **None**.
4. Build command: **bash build.sh**.
5. Build output directory: **dist**.
6. Deploy. Надалі push у main запускатиме новий деплой.

Локальний запуск: із кореня репозиторію виконати команду python3 -m http.server 8080 та відкрити http://localhost:8080.

## Реально реалізовані функції

- Імпорт власних відео, фото, аудіофайлів. Файли зберігаються в IndexedDB; проєкт — у localStorage.
- Послідовна відеодоріжка: перетягування для перестановки, видалення, розрізання в позиції курсора, trim у властивостях, зображення з заданою тривалістю.
- Окремі текстові й субтитрові шари з часом початку та тривалістю; анімації fade / slide / pop; ручний ввід субтитрів та імпорт SRT.
- Окремі аудіодоріжки, регулювання гучності, **запис голосу з мікрофона** (потрібен HTTPS і дозвіл).
- Пропорції 9:16 (720 × 1280), 4:5 (864 × 1080), 1:1 (1080 × 1080), 16:9 (1280 × 720).
- Canvas-перегляд та локальний експорт через Canvas.captureStream, Web Audio API, MediaRecorder; MP4 лише у підтримуваних браузерах, інакше WebM.
- Жоден завантажений файл не відправляється на відеосервер.

## Якість відео та експорт

- Раніше всі вертикальні ролики рендерилися на Canvas **720×1280**, навіть якщо оригінал був Full HD. Попередній перегляд тепер працює з базовою роздільністю **1080×1920** для 9:16, **1920×1080** для 16:9, **1080×1350** для 4:5 та **1080×1080** для 1:1.
- Додано налаштування якості у діалозі експорту: **HD 720p — 8 Мбіт/с**, **Full HD 1080p — 16 Мбіт/с (типово)**, **2K 1440p — 28 Мбіт/с**, **4K 2160p — 48 Мбіт/с (експериментально)**. Частота — 30 fps. Аудіобітрейт запитується до 256 кбіт/с.
- Для вихідних зображень і відеофрагментів увімкнене якісне Canvas-згладжування під час масштабу.
- Відеобітрейт для MediaRecorder — **запитане значення**, браузер/кодек має право використати інше. Експорт виконується у реальному часі і може пропускати кадри на слабкому обладнанні. 4K помітно навантажує CPU/GPU і пам’ять.
- Вибір 4K **не відновить деталей**, відсутніх в оригінальному файлі. Редактор завжди повторно кодує файл, тому абсолютно безвтратної якості не гарантує.
- При завершенні/скасуванні експорту Canvas повертається до Full HD роздільності попереднього перегляду.
- GitHub Actions перевіряє параметри роздільності/бітрейту та створення короткого реального відеофайлу у Chromium; за наявності ffprobe також перевіряє його розміри.

## Автоматичні субтитри з відео — мультимовний режим

Натисни **відеокліп на монтажній шкалі** → у правій панелі **ВЛАСТИВОСТІ** відкриється інструмент **«АВТОСУБТИТРИ З ГОЛОСУ»**. Встанови **«МОВА МОВЛЕННЯ → Автоматично визначити»** чи конкретну мову, вибери попередній стиль і натисни **«АВТОСУБТИТРИ З ВІДЕО · ШІ»**.

**Функціональність:**
- Підтримується автоматичне визначення мови Whisper, включно з польською; за потреби мову можна вказати вручну. Модель багатомовна, але точність залежить від запису, акценту, фонової музики й ресурсу браузера. Примусова українська мова, яка спотворювала польську, прибрана.
- Ролики до **30 секунд** тепер розпізнаються як **цілісний фрагмент**, без втрати контексту на кожних 15 секундах. Для довших записів використовуються перекривні **30-секундні вікна** із кроком **28 секунд**. Це зменшує ризик втрати мовлення після перших секунд. Кожному слову/фразі присвоюються таймкоди лише там, де модель реально виявила мовлення.
- **Повна область автосубтитрів** на окремій доріжці розтягується на всю тривалість обраного відеофрагмента, навіть якщо людина мовчить наприкінці. Це тільки монтажна область; написи не розтягуються в тишу.
- Під час повторної генерації автосубтитри того самого джерела замінюються, а не дублюються. Вручну додані субтитри та імпортовані SRT не видаляються.
- Статус розпізнавання тепер — компактний блок у медіатеці, з індикатором відсотків при завантаженні/витягуванні звуку та коротким підсумком.
- **Редактор субтитрів:** вибір шрифту (Arial, Arial Black, Impact, Trebuchet, Verdana, Georgia), розміру, висоти розміщення, кольору тексту, підсвіченого слова, обводки, підкладки, плавної появи, підйому чи пружної анімації. Кнопка **«Застосувати до всіх фраз відео»** переносить оформлення на всі автоматичні субтитри вибраного джерела.
- Результат вбудовується в Canvas-рендер і відеоекспорт разом із фоновими ефектами.

**Моделі розпізнавання:** за замовчуванням **Whisper Base (покращена)**, окремо **Whisper Small (максимальна, WebGPU)** та **Whisper Tiny (швидка, найменш точна)**. Моделі завантажуються лише за вибором користувача; Whisper Small значно вимогливіша до пам'яті та відеоприскорення. Код використовує не сильно квантизований аудіоенкодер (fp16 для WebGPU, fp32 для CPU), щоб зберегти більше деталей мовлення. Поширену галюцинацію «Thank you for watching this video» й подібні шаблонні фрази редактор не публікує; якщо модель видала тільки їх, старі субтитри залишаться без змін, а користувач отримає зрозумілу помилку. Це НЕ гарантує відсутності інших помилок. Модель і бібліотека завантажуються через інтернет при першому запуску, а сам запис обробляється на пристрої. Звук з відео наразі витягується локальним MediaRecorder у **реальному часі** (20 с відео ≈ 20 с лише на витягування). Поточний ліміт **10 хвилин**. Якщо наприкінці не розпізнано слова, редактор повідомляє про це; він не вигадує відсутній текст. Розпізнані слова та часові позначки потрібно перевірити вручну перед рекламним використанням.

**Захист від галюцинацій (оновлення):** WebGPU Whisper використовує **fp32-енкодер** замість fp16, щоб знизити ризик спотворення акустичних ознак; у декодері запитуються параметри проти повторень. Результат перевіряється до запису на монтажну шкалу: стандартні вигадані шаблони на кшталт «Thank you for watching this video», слова аномальної довжини, нескінченні склади на кшталт «kokokokoko» та надмірні повтори відхиляються. Якщо результат недостовірний, **попередні субтитри залишаються без змін**; для очищення є кнопка **«ВИДАЛИТИ АВТОСУБТИТРИ ЦЬОГО КЛІПУ»** в інспекторі. Автоматичний фільтр не замінює реального контролю польської транскрипції.

Відображення контролів розпізнавання перенесено з лівої постійної панелі до **панелі властивостей вибраного відео/аудіо**, щоб не перевантажувати медіатеку. Параметри моделі й мови запам'ятовуються на цьому пристрої.

## Обмеження MVP

- Це **не** завершений After Effects/CapCut: немає складного композитингу, довільних keyframes, розвинених переходів, професійного кольорокору, багатошарового відео.
- **AI-субтитри й TTS-генерація голосу не реалізовані.** Є ручні субтитри, SRT, запис та імпорт озвучки. Для AI потрібен додатковий локальний рушій і перевірка ліцензій моделей.
- Браузерний експорт виконується **в реальному часі**. Підтримка MP4/H.264, точність A/V sync, запис складних проєктів залежать від браузера й обладнання. Для універсального MP4 потрібен додатковий FFmpeg/WASM або інший рендерер.
- Це HD (720–1280 px за довшою стороною), не 4K.
- Немає undo/redo, командного доступу, синхронізації між пристроями, хмарного сховища чи акаунтів.
- Дані зберігаються в цьому браузері. Очистка browser storage або приватний режим можуть їх знищити. Великі медіафайли можуть вичерпати локальну квоту.
- Запис голосу залежить від дозволу на мікрофон. Для музики/відео потрібні належні права.

## Технічна архітектура

Статичні HTML/CSS/JavaScript без бекенду; IndexedDB і Object URLs для файлів; Canvas 2D для композицій; HTMLVideoElement для декодування; Web Audio API для доріжок; MediaRecorder для експорту.

**Жодних платних API або ліцензій.** Cloudflare Pages роздає тільки статичні файли. Монтаж і рендер навантажують пристрій користувача.

## Наступні кроки

1. Перевірити в Chrome/Edge реальне вертикальне відео й аудіозапис.
2. Стабілізувати аудіо-відео синхронізацію, додати FFmpeg.wasm для H.264 fallback.
3. Додати локальну транскрипцію Whisper та TTS із перевіреними ліцензіями.
4. Реалізувати Undo/Redo, ключові кадри, декілька відеошарів, аудіохвилі й пакетний експорт.

**Статус:** початковий функціональний MVP. GitHub Actions перевіряє синтаксис і статичну збірку, а не реальний відеорендер у браузері. Перед клієнтськими проєктами потрібні інтеграційні тести на відеоматеріалах.
