# PTS Creative Studio — Video Montage MVP

Безкоштовний онлайн-відеоредактор для рекламних креативів, який можна розгорнути на **Cloudflare Workers (Static Assets)** або **Cloudflare Pages**. Без платних ліцензій, AI API, серверів рендеру чи платних SDK.

## Cloudflare Workers (як на поточному екрані Create application)

Налаштування для GitHub-репозиторію **SviatF/video-motaz**:

- Project name: **video-motaz**
- Build command: **bash build.sh**
- Deploy command: **npx wrangler deploy**
- Preview command: **npx wrangler preview**
- Production branch: **main**

У корені є файл **wrangler.json** із `assets.directory = "./dist"` — саме він повідомляє Workers, що після запуску build.sh слід публікувати статичний сайт із папки dist. Після першого деплою Workers Builds відстежуватиме push у main.

## Cloudflare Pages (GitHub deploy)

1. Cloudflare Dashboard → **Workers & Pages** → **Create application** → **Pages** → **Import an existing Git repository**.
2. Вибрати **SviatF/video-motaz**, production branch **main**.
3. Framework preset: **None**.
4. Build command: **bash build.sh**.
5. Build output directory: **dist**.
6. Deploy. Надалі push у main запускатиме новий деплой.

Локальний запуск: із кореня репозиторію виконати команду python3 -m http.server 8080 та відкрити http://localhost:8080.

## Реально реалізовані функції

- Імпорт власних відео, фото, аудіофайлів. Файли зберігаються в IndexedDB; проєкт — у localStorage.
- Послідовна відеодоріжка: перетягування для перестановки, видалення, розрізання в позиції курсора, trim у властивостях, зображення з заданою тривалістю.
- Окремі текстові й субтитрові шари з часом початку та тривалістю; анімації fade / slide / pop; ручний ввід субтитрів та імпорт SRT.
- Окремі аудіодоріжки, регулювання гучності, **запис голосу з мікрофона** (потрібен HTTPS і дозвіл).
- Пропорції 9:16 (720 × 1280), 4:5 (864 × 1080), 1:1 (1080 × 1080), 16:9 (1280 × 720).
- Canvas-перегляд та локальний експорт через Canvas.captureStream, Web Audio API, MediaRecorder; MP4 лише у підтримуваних браузерах, інакше WebM.
- Жоден завантажений файл не відправляється на відеосервер.

### Emoji — 3963 символи Unicode Emoji 18.0

- **3963 fully-qualified emoji-послідовностей** з офіційного файлу emoji-test.txt (Unicode 18.0): емоції, люди, жести й відтінки шкіри, тварини, їжа, подорожі, спорт, предмети, символи, прапори.
- Категорії українською, пошук за англійськими назвами й поширеними українськими словами, популярні emoji на початку каталогу та порційне відображення по 96 символів.
- **Натисни emoji**, щоб додати його як анімований шар у доріжку «СТІКЕРИ / FX». Налаштовуються час, тривалість, позиція X/Y, масштаб, поворот, швидкість руху та сам emoji в інспекторі.
- **16 анімацій:** Bounce, Heartbeat, Bounce In, Pop, Pulse, Float, Swing, Spin, Jitter, Orbit, Drop, Wiggle, Blink, Slide, Flip, Drift. Вкладка «АНІМАЦІЇ» також додає готові анімовані emoji-шари.
- **27 векторних CTA/стікерів**, **16 FX-пресетів** та 5 оригінальних синтезованих музичних лупів.

**Сумісність Unicode.** Unicode 18.0 містить нові emoji й комбінації. Кольорове відображення на сайті та в Canvas/експорті **залежить від системних emoji-шрифтів, браузера й ОС**. На старих пристроях частина може відображатися як квадрат, текстовий символ чи неповна комбінація. Ми не вбудовуємо чужі emoji-зображення чи шрифти. Щоб гарантувати абсолютно однаковий вигляд на всіх пристроях, потрібен додатковий власний або належно ліцензований графічний набір.

## Обмеження MVP

- Це **не** завершений After Effects/CapCut: немає складного композитингу, довільних keyframes, розвинених переходів, професійного кольорокору, багатошарового відео.
- **AI-субтитри й TTS-генерація голосу не реалізовані.** Є ручні субтитри, SRT, запис та імпорт озвучки. Для AI потрібен додатковий локальний рушій і перевірка ліцензій моделей.
- Браузерний експорт виконується **в реальному часі**. Підтримка MP4/H.264, точність A/V sync, запис складних проєктів залежать від браузера й обладнання. Для універсального MP4 потрібен додатковий FFmpeg/WASM або інший рендерер.
- Це HD (720–1280 px за довшою стороною), не 4K.
- Немає undo/redo, командного доступу, синхронізації між пристроями, хмарного сховища чи акаунтів.
- Дані зберігаються в цьому браузері. Очистка browser storage або приватний режим можуть їх знищити. Великі медіафайли можуть вичерпати локальну квоту.
- Запис голосу залежить від дозволу на мікрофон. Для музики/відео потрібні належні права.

## Технічна архітектура

Статичні HTML/CSS/JavaScript без бекенду; IndexedDB і Object URLs для файлів; Canvas 2D для композицій; HTMLVideoElement для декодування; Web Audio API для доріжок; MediaRecorder для експорту.

**Жодних платних API або ліцензій.** Cloudflare Pages роздає тільки статичні файли. Монтаж і рендер навантажують пристрій користувача.

## Наступні кроки

1. Перевірити в Chrome/Edge реальне вертикальне відео й аудіозапис.
2. Стабілізувати аудіо-відео синхронізацію, додати FFmpeg.wasm для H.264 fallback.
3. Додати локальну транскрипцію Whisper та TTS із перевіреними ліцензіями.
4. Реалізувати Undo/Redo, ключові кадри, декілька відеошарів, аудіохвилі й пакетний експорт.

**Статус:** початковий функціональний MVP. GitHub Actions перевіряє синтаксис і статичну збірку, а не реальний відеорендер у браузері. Перед клієнтськими проєктами потрібні інтеграційні тести на відеоматеріалах.
